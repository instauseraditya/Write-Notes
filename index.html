Note mode — write without friction

A full mini editor in a sticky note. Format as you think; tables and lists stay editable.

  • Bullet and numbered lists with style controls
  • Insert tables; add or remove rows and columns; resize cells

Draw mode — sketch on an infinite canvas

Capture diagrams and freehand thoughts next to your research tab.

Nodes mode — map connected ideas

Build lightweight mind maps without opening another app.

  • Double-click the canvas to add a node
  • Tab to create a child from the selected idea
  • Drag to rearrange; links update automatically
  • Per-node colors or cascade styles to children
  • Export outline text, PNG, SVG, or JSON

FAQ

Does it work on every website?
Notes can float on most normal web pages. Restricted Chrome pages (like chrome:// settings) cannot host content scripts; use the built-in notes board instead.
Where are my notes stored?
Locally in your browser via Chrome’s storage API. They stay on your device unless you export or share a zip.
Can I export my work?
Yes. Export text, PDF, HTML, drawings as images, node maps, or a full zip including a sticky-note JSON backup.
Is Write Notes free?
Yes. You can use the extension for free. Optional donations support ongoing development.
